# AIStream 影视 · 四端统一项目

覆盖 **电脑桌面端 / iOS / 安卓 / TV 大屏端** 的完整可运行项目。四端核心功能严格一致：**影视内容浏览、搜索、详情查看、播放入口**；按键盘鼠标、触摸、遥控器三种输入方式分别设计布局与导航，不是简单缩放或拉伸。

> 当前版本：顶部栏目按**影视类型**区分（电影 / 电视剧 / 动漫 / 综艺 / 短剧 / 纪录片 / 点播 / IPTV），「我的」快捷入口按真实接口返回渲染，播放为**四端共用的 ArtPlayer 开源内核**（m3u8 / mp4、选集分页、线路标签、弹幕插件、TV 遥控，UI 参考腾讯视频）；跨域片源经四端 `/api/proxy?u=` 中转（分片与密钥 URI 重写、Range 透传）。详见 [08-影视类型栏目与内置播放器.md](docs/08-影视类型栏目与内置播放器.md)。

## 快速运行（零依赖，只需 Node 18+ 或 Python 3）

```bash
cd AIStream
npm start                  # 或：python3 -m http.server 5173
```

| 端 | 地址 | 输入方式 |
|----|------|---------|
| 启动台（按 UA 自动分发 / 手动选择） | `http://127.0.0.1:5173/` | — |
| 电脑桌面端 | `http://127.0.0.1:5173/desktop.html` | 键盘 + 鼠标 |
| iOS / 安卓移动端 | `http://127.0.0.1:5173/mobile.html` | 触摸 |
| TV 大屏端 | `http://127.0.0.1:5173/tv.html` | 遥控器 |

> 任意端右下角有 `DESKTOP / MOBILE / TV` 切换器，也可用 `?platform=tv` 强制进入指定端，方便一次验收四端一致性。
> ES Modules 需要 http 协议，请勿直接双击用 `file://` 打开 HTML。

自检：

```bash
npm run check
```

## 原生安装包（.exe / .apk / TV .apk / .ipa）

| 端 | 格式 | 产物 | 状态 |
|----|------|------|------|
| 电脑桌面端 | `.exe` | `dist-win/AIStream-Setup-1.0.0.exe`（NSIS 安装程序）、`AIStream-Portable-1.0.0.exe`（免安装） | ✅ 已构建 |
| 安卓手机 | `.apk` | `dist/AIStream-Mobile-1.0.0.apk` | ✅ 已构建并签名 |
| Android TV | `.apk` | `dist/AIStream-TV-1.0.0.apk` | ✅ 已构建，含 Leanback 适配 |
| iOS | `.ipa` | `dist/ipa/AIStream.ipa` | ⚠️ 需在 macOS + Xcode 上执行 `ios/build-ipa.sh` |

Windows 一键构建：直接运行 `build-all.bat`（或 `npm run build:all`）。
`.apk` 使用本机 Android SDK 自带的 aapt2/d8/apksigner **零 Gradle 依赖**构建；TV 版含 `LEANBACK_LAUNCHER`、leanback feature、非必需触摸屏、横屏、TV Banner 与遥控器按键注入。
**Windows 无法产出 `.ipa`**（Xcode/codesign 仅 macOS），已提供 Mac 一键脚本与导出配置。

完整说明见 [docs/05-原生安装包构建说明.md](docs/05-原生安装包构建说明.md)。

## 关键约束与本次处理

| 约束 | 处理 |
|------|------|
| 影视数据仅对接自建内容源 | 内容源地址由部署方在配置中填写，不接第三方、不内置离线内容，也不在文档中公开固定地址 |
| 地址/字段/参数以**实测**为准，不得编造 | 已对站点实测并把真实协议/接口/参数/鉴权/字段内置；未确认字段留空，**不填任何示例片名、海报、集数、评分、播放链接** |
| 未提供的信息集中列为「待补充项」 | 代码 `PENDING_ITEMS` 与 [docs/00-待补充项清单.md](docs/00-待补充项清单.md) 逐项对应，共 **17 项**；界面顶部实时显示计数 |
| 采用参考「影视」UI 样式 | 深色底、紫粉渐变品牌字、半透明搜索胶囊、横滑频道、焦点轮播、蓝色「高清」角标、分区标题 + 箭头、2:3 海报 |
| 去掉「独家大瓜」 | 直接移除，不改名顶替 |
| 去掉「游戏中心」 | 替换为 **「榜单」**（影视内容向） |
| 四端核心功能严格一致 | 共用 `src/core/store.js`，功能清单在 `src/core/config.js` 的 `CORE_FEATURES` 中锁定 |
| 分别设计布局与导航 | 三套独立 DOM + 三套独立 CSS，见下表 |

### 三端设计差异（不是缩放）

| | 电脑桌面端 | iOS / 安卓 | TV 大屏端 |
|---|---|---|---|
| 主导航 | 左侧固定竖栏 + 数字键 1–4 | 底部 4 Tab + 安全区 | 左侧大焦点竖栏 |
| 搜索 | 顶栏胶囊，`/` 聚焦，防抖 + 回车 | 顶栏胶囊，触摸 + 键盘搜索键 | 独立搜索面板，遥控器搜索键 |
| 内容组织 | 大 Hero + 侧焦点位 + 自适应多列网格 | 大焦点轮播 + 三列海报 + 分区 | 10-foot 横向货架 Rows，左右键平移 |
| 详情 | 右侧滑出抽屉，Esc / 遮罩关闭 | 整页上滑 push，返回按钮 | 全屏沉浸，BACK 返回 |
| 反馈 | hover 放大 + 悬浮操作按钮 | tap / swipe 手势 | 唯一通道：焦点放大 + 金色描边光晕 |
| 特有 | 底部状态栏、快捷键、面包屑 | 安全区 `env(safe-area-inset-*)`、状态栏 | overscan 安全区、空间焦点导航、无 hover/滚动条 |

## 数据源状态（已实测接入）

已对自建内容源实际探测并接入：协议 `http`、自研 `/api/*`、Bearer 登录、首页 `api/home`、搜索 `api/search?q=`、播放 `api/play?sid=&vid=`。因响应无 CORS 头，四端均通过**同源代理**转发。内容源地址、端口与凭据由部署方自行配置，不在本仓库文档中公开。完整实测记录见 [docs/06-影视网站对接实测报告.md](docs/06-影视网站对接实测报告.md)。

**唯一剩下的一步：在应用里登录**（站点 `needLogin=true`，也支持注册）。输入你的主站账号后，按影视类型区分的真实内容、海报、搜索结果、详情与内置播放会自动出现；token 只存本设备，项目不内置任何账号或凭据。

剩余 17 项待补充见 [docs/00-待补充项清单.md](docs/00-待补充项清单.md)。
