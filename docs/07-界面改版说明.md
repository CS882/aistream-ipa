# AIStream 影视 · 界面改版说明

> 依据 2026-11-15 需求方提供的四张截图逐项调整。原界面中「调试向」的信息全部移除或换成影视应用常见内容，四端保持一致的核心能力，但按各自输入方式独立呈现。

---

## 一、分类（截图 1）

顶部频道改为**主站真实分类**，不再使用写死的参考图分类：

| 分类 id | 显示名 | 来源 |
|---------|--------|------|
| `rec` | 推荐 | `app.js` 的 `CUR_KIND='rec'` |
| `movie` / `series` / `anime` / `variety` / `short` / `doc` | 电影 / 剧集 / 动漫 / 综艺 / 短剧 / 纪录片 | `app.js` 的 `KINDNAME`，与分类截图一致 |

- 点击分类 → `GET /api/up/catalog?kind=<kind>&limit=&page=1`（二次实测的真实分类榜单接口）；失败依次回退 `api/home/cat?idx=0&t=`、`api/home/cat?t=`，最后回退 `/api/home` 的真实内容并给出提示。
- 顶部频道固定为**影视类型**；`/api/home` 的 `columns` 只用于首页内容，不再覆盖频道名（详见 [08-影视类型栏目与内置播放器.md](./08-影视类型栏目与内置播放器.md)）。
- 快捷入口按截图补齐并接上真实接口：我的追剧 `api/weekly`、积分中心 `api/points/me`、我的预约 `api/preview/reserved`、历史记录 `api/history`、我的收藏 `api/fav`、IPTV 直播 `api/iptv`。点击后在「我的」页宽容展示内容源真实返回，不假设字段结构。

## 四、Hero 接真实数据（截图 4）

`src/components/extras.js` 的 `heroMain()` / `heroMini()` 使用 `/api/home` 返回的真实条目：

- 背景海报（经 `api/dimg?u=` 代理防防盗链）、片名、栏目 / 年份；
- 「播放」「查看详情」按钮携带真实 `id`，播放走 `/api/play?sid=&vid=`；
- 轮播指示点按真实条目数量生成；
- 无真实条目时只显示中性的「暂无焦点内容」，不再出现调试说明文案。

三端呈现：
- **桌面**：左侧大 Hero + 右侧两个小焦点位；
- **移动**：单幅高 218px 焦点 Banner + 指示点；
- **TV**：横向 16:9 大卡货架，遥控器方向键驱动 `FocusManager`，OK 进入详情。
