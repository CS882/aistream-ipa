## 三、不依赖上述信息、已经完成的部分

- 四端可运行入口与统一业务内核（`src/core/store.js`），四端共用。
- 三套**独立**布局与导航：桌面键鼠 / 移动触控 / TV 遥控器，非缩放。
- 顶部栏目按影视类型区分（推荐 / 电影 / 电视剧 / 动漫 / 综艺 / 短剧 / 纪录片 / 点播 / IPTV）。
- 四项核心功能（浏览、搜索、详情、播放）全部贯通；详情含简介 / 导演 / 主演 / 评分 / 类型。
- 内置 ArtPlayer 开源内核（弹幕插件 + HLS），选集分页（2000+ 集不卡）、线路标签、续播、自动换源。
- 筛选：类型 / 国家 / 年份 / 排序四行，地区做标准化映射（华语、欧美、日韩、港台可展开到具体国家），支持评分排序。
- 四端 `/api/proxy?u=` 流中转：跨域 m3u8 自动走本机中转，分片与密钥 URI 重写，Range 透传、302 跟随。
- 四端共用登录 / 注册组件，记住账号密码；TV 端提供遥控器虚拟键盘。
- Windows `.exe`（安装版 + 便携版）、安卓手机 `.apk`、Android TV `.apk` 已实际构建；iOS 提供 macOS 一键 `.ipa` 脚本。
- 巨魔（TrollStore）免签名 IPA：GitHub Actions 云端构建 + Mac 本地脚本两条路径，`ldid -S` 伪签名、无需开发者账号，内置公网网关（见 [14-巨魔IPA构建与网关部署.md](./14-巨魔IPA构建与网关部署.md)）。
- 交付自检 `npm run check`（57 项）。
