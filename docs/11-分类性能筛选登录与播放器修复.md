# AIStream 影视 · 分类性能、腾讯视频筛选、登录与播放器修复

> 2026-11-16 凌晨第二轮。需求：短剧/纪录片仍卡、筛选按腾讯视频（类型/年份/国家）、播放页选集重叠、点击封面直接播放、登录注册与记住密码、后台缓存与暂停缓存、整体审核。

---

## 一、短剧 / 纪录片为什么还卡

两类都走 `api/up/catalog?kind=short|doc`，站点对这两类上游扫描更慢；原来统一 20 秒超时，且失败后回退首页要**再等一次** `/api/home`。

修复：

| 措施 | 说明 |
|------|------|
| 分类短超时 | 短剧/纪录片 8 秒，其它分类 12 秒；超时提示明确写「内容源响应超时（8 秒）」 |
| 首页缓存优先回退 | 回退时直接用内存里的 `homeCache`，不再二次请求 |
| 后台预取 | 登录后 1.5 秒起，依次预取各分类首屏（`prefetchCategories`），点短剧/纪录片通常直接命中缓存 |
| 缓存持久化 | 列表缓存写入 localStorage（16 条，5 分钟 TTL），冷启动也能秒开 |
| 缓存命中不显示 loading | `refresh()` 命中缓存时直接渲染，不闪骨架 |

实测（模拟接口卡死）：`耗时 8.0s | ok=true | 回退条目=1 | notice=内容源响应超时（8 秒）；该分类暂无独立条目，已显示首页内容`。

## 二、筛选改为腾讯视频式（类型 / 国家 / 年份 / 排序）

`src/components/filters.js` 重写为四行，每行首项「全部 / 默认」（贴合截图形式）：

| 行 | 选项 | 说明 |
|----|------|------|
| 类型 | 全部 / 电影 / 电视剧 / 动漫 / 综艺 / 短剧 / 纪录片 | 站点实测 kind |
| 国家 | 全部 + 21 个国家（中国大陆、美国、中国香港、中国台湾、日本…） | 按条目真实 `area` **包含匹配**，含别名（华语/大陆/港/台…） |
| 年份 | 全部 / 2026 / 2025 / 2020年代 / 2010年代 / 2000年代 / 90年代 / 更早 | 按真实 `year` 分组 |
| 排序 | 默认 / 时间 / 名称 / 热度（禁用）/ 评分（禁用） | 热度、评分站点未提供字段，置灰并标注 |

实测：4 行、42 个选项、2 个禁用；国家「中国大陆」能匹配 `area=华语`，年代 2010s 能匹配 2015/2018，时间排序 2026→2018→2015。

## 三、播放页选集重叠

根因：侧栏是 grid + 选集 `max-height:48vh`，选集内容与「播放信息」争抢高度，移动端更明显。

修复：侧栏改 `flex-direction: column`，选集 `flex:1 1 auto; min-height:0; max-height:none`，播放信息 `flex:none`；移动端隐藏「播放信息」、选集横滑；功能条 `bottom` 调到 64px（移动 56px），不再压 ArtPlayer 控制条。

实测：`SIDE=flex | DIR=column | GROW=1 | OVERLAP=false | TBAR_BOTTOM=64px`。

## 四、点击封面直接播放

- 桌面 / 移动 / TV：点卡片 → `store.requestPlay(id)` 直接进播放器。
- 详情入口保留：每张海报右上角新增 `i` 按钮（`data-action="detail"`），移动端常驻、桌面 hover 显示；桌面原有 hover「详情」按钮仍然有效。

## 五、登录页：注册按钮 + 记住账号密码

- 登录按钮旁新增显眼的「注册新账号」次级按钮（注册模式变「返回登录」）。
- 新增「记住账号密码」勾选（默认勾选，可取消），保存在本机 `localStorage.aistream_remember`，下次打开自动填充用户名与密码；取消勾选只保留用户名。
- 勾选框加了 `data-focusable`，TV 遥控器可操作。
- 实测：`USER=demo_user | PASS=demo_pass | CHECKED=True`。

## 六、后台缓存与暂停缓存

- **提前缓存**：登录后后台串行预取 6 个分类首屏；列表缓存持久化到 localStorage，二次启动直接用。
- **暂停缓存**：暂停时保存续播进度（标题+集名 → 秒数，最多 40 条），并调用 `hls.startLoad()` 继续缓冲，恢复播放即可续上。
- **续播**：打开同一集时，若进度 >5 秒且不在片尾，自动 seek 并提示「已从 mm:ss 继续播放」；播放中每 10 秒保存一次，关闭前也保存。

## 八、审核：还需要改什么（按优先级）

**P0（影响看片）**
1. **服务端流中转**：第三方 m3u8 多数不带 CORS，HLS 会报网络错误；目前靠自动换源兜底。加 `/api/proxy?u=`（支持 Range/302）能救回大部分线路，是当前投入产出最高的一项。
2. **地区字段标准化**：现在按 `area` 包含匹配（「中国大陆」也能命中「华语」），但站点若返回「美国/欧美」这类笼统值，筛选会不精确。最好让站点提供标准国家字段。
3. **筛选只覆盖当前一页**：前端筛选只对已加载的 48 条生效。要全量筛选必须让站点支持 `area/year/sort` 参数（需确认接口）。

**P1（体验）**
4. **续播 key 用标题+集名**：改名或换线路会失效，建议改为内容 id + 集序号（需要 `resolvePlay` 回传 id）。
5. **TV 登录**：遥控器输入账号密码很痛苦，建议 TV 端做「手机扫码/手机号验证码登录」。
6. ~~**详情页信息少**：站点无独立详情接口。~~ → 已解决：三次实测找到 `api/up/detail`，简介 / 导演 / 主演 / 评分均已接入（见 docs/12）。
7. **热度/评分排序**：站点没有字段，已置灰；拿到字段后可做「热度榜/评分榜」。

**P2（工程与发布）**
8. 图片尺寸参数与下一页预取，降低首屏流量。
9. 播放失败埋点（线路失败率），为流中转与线路排序提供依据。
10. 正式签名 / 包名 / 图标 / iOS Team ID（待补充项 P-08~P-17）。
11. 记住密码是明文存本机，已在界面提示；若要更安全可改为只记用户名 + 系统钥匙串（需原生能力）。
