# AIStream 影视 · 各端运行说明

## 〇、通用前提

- 项目**核心运行零 npm 依赖**（原生 ES Modules + CSS），只需 Node 18+ 或 Python 3。
- ES Modules 必须通过 http 协议加载，**不要用 `file://` 直接双击 HTML**。
- 影视内容源仅使用需求方提供的 `fnos.jiulingkeji.asia:8890`；接口已实测对接（登录、分类、搜索、详情、播放链路见 [06-影视网站对接实测报告.md](./06-影视网站对接实测报告.md)）。
- iOS 巨魔（TrollStore）免签名 IPA 的构建与网关部署见 [14-巨魔IPA构建与网关部署.md](./14-巨魔IPA构建与网关部署.md)。

## 一、一次启动，四端可访问

```bash
cd AIStream
npm start
# 等价于 node server.js，默认 http://127.0.0.1:5173
```

自定义端口 / 允许局域网设备（手机、TV 真机）访问：

```bash
PORT=8080 HOST=0.0.0.0 npm start
# 然后在手机 / TV 浏览器访问 http://<电脑局域网IP>:8080/mobile.html 或 /tv.html
```

> 用 Python 也可以：`python3 -m http.server 5173 --bind 0.0.0.0`（同样需在项目根目录执行）。

启动后终端会打印四个地址：

| 端 | URL |
|----|-----|
| 启动台（自动分发 / 手动选端） | `/` |
| 电脑桌面端 | `/desktop.html` |
| iOS / 安卓移动端 | `/mobile.html` |
| TV 大屏端 | `/tv.html` |

**验收切换器**：任意端右下角 `DESKTOP / MOBILE / TV`；或 URL 加 `?platform=tv` 强制进入。

## 二、电脑桌面端

### 立即可运行
浏览器打开 `/desktop.html`。这是完整的桌面端入口：侧边栏导航、顶栏搜索、多列自适应网格、鼠标悬浮操作、右侧详情抽屉、底部状态栏、键盘快捷键全部可用。

### 打包成独立桌面应用（可选增强）

```bash
npm i -D electron
npm run desktop
```

`electron-main.cjs` 会在主进程起一个最小本地 http 服务（ES Modules 需要 http），打开 1440×900 的独立窗口加载 `desktop.html`。无需额外依赖或外部 Node 运行时。

> 打包分发所需的应用标识、签名信息为待补充项 P-26。

### 键鼠对照

| 操作 | 效果 |
|------|------|
| `/` | 聚焦搜索框 |
| 输入关键词（防抖 320ms）/ 回车 | 搜索 |
| `1` `2` `3` `4` | 切换 首页 / 筛选 / 榜单 / 我的 |
| `←` `→` | 切换顶部频道 |
| `Esc` | 关闭详情抽屉；否则清空搜索 |
| 鼠标悬浮卡片 | 放大 + 出现「详情 / 播放」按钮 |
| 点击卡片 / 焦点位 | 打开右侧详情抽屉 |

## 三、iOS / 安卓移动端

### 立即可运行（PWA，零依赖）

1. 用 `HOST=0.0.0.0 npm start` 启动；
2. 手机浏览器访问 `http://<电脑局域网IP>:5173/mobile.html`；
3. iOS Safari「分享 → 添加到主屏幕」/ 安卓 Chrome「安装应用」，即以全屏 standalone 运行（已配置 `public/manifest.json` + `sw.js` + 安全区适配）。

界面按参考图还原：状态栏、顶部半透明搜索胶囊、横滑频道、大幅焦点轮播、三列海报、底部 4 Tab、整页上滑详情。iOS 与安卓通过 UA 细分 `data-flavor`，安全区使用 `env(safe-area-inset-*)`。

> 桌面浏览器打开 `/mobile.html` 时会出现手机预览外框，这只是验收容器，**不是把桌面界面缩小**；移动端 DOM 与交互完全独立。

### 触摸对照

| 操作 | 效果 |
|------|------|
| 点按底部 Tab | 切换 首页 / 筛选 / 榜单 / 我的 |
| 左右滑动顶部频道 | 横滑浏览频道（scroll-snap） |
| 焦点轮播左右滑动 | 切换焦点指示位 |
| 点按海报 | 整页上滑详情 |
| 详情左上返回 / 安卓物理返回 | 关闭详情 |
| 搜索框回车 / 点放大镜 | 搜索 |

### 原生打包（可选，需补充信息）

```bash
npm i -D @capacitor/cli @capacitor/core
npm i @capacitor/ios @capacitor/android
# 先在 capacitor.config.json 补 appId（P-27 / P-28）
npm run mobile:ios       # cap sync ios && cap open ios       → 需 Xcode + macOS
npm run mobile:android   # cap sync android && cap open android → 需 Android Studio
```

> `appId` 当前为空字符串，是需求方未提供的待补充项，**不是遗漏值，也不做假设**。

## 四、TV 大屏端

### 立即可运行

TV 浏览器 / 智能电视自带浏览器访问 `http://<电脑局域网IP>:5173/tv.html`；或在开发机上直接打开 `/tv.html`，用键盘方向键模拟遥控器验收。

TV 端为 10-foot UI：大字号、大间距、overscan 安全区、左侧大焦点导航、横向货架 Rows、全屏沉浸详情，**无 hover、无滚动条、无鼠标指针**。焦点由自研 `FocusManager` 用几何方位做空间导航（方向键找最近可焦点元素），不是把移动界面放大。

### 遥控器按键映射（兼容集）

| 遥控器按键 | 浏览器按键 / keyCode | 行为 |
|-----------|---------------------|------|
| 方向键 上/下/左/右 | `ArrowUp/Down/Left/Right`，`38/40/37/39` | 移动焦点；左右驱动整行货架平移 |
| OK / 确认 | `Enter`、`NumpadEnter`、`Space`，`13/23/66/32` | 激活当前焦点 |
| BACK / 返回 | `Escape`、`Backspace`、`BrowserBack`，`4/461/8` | 关闭详情 / 退出搜索 / 清空搜索 |
| 搜索键 | `/`、`F3`、`S`，`82` | 打开 / 关闭搜索面板 |
| 播放键 | `MediaPlayPause` / `MediaPlay` | 触发播放入口 |

> **P-29 待补充**：不同厂商遥控器的 OK / Back / 菜单键 keyCode 可能不同，需在目标设备上实机核对后调整 `tv.js` 顶部的 `KEY_ACTION` / `KEYCODE_ACTION`。

### Android TV WebView 壳（可选）

用 Android Studio 建一个 Android TV 项目，WebView 加载 `tv.html` 并开启 JavaScript / DOM Storage，把遥控器 `dispatchKeyEvent` 映射为上述按键。所需最低系统版本、包名、图标均为待补充项（P-28 / P-34 / P-35）。

## 六、常见问题

| 现象 | 原因 / 处理 |
|------|------------|
| 页面空白、控制台报 CORS / module 错误 | 用了 `file://`；改用 `npm start` 的 http 地址 |
| 手机 / TV 打不开 | 服务默认只监听 `127.0.0.1`；用 `HOST=0.0.0.0 npm start` 并确认同一局域网 |
| 打开后要求登录 | 预期行为：实测站点 `needLogin=true`，请在应用内输入主站账号（或注册）；登录后自动显示按影视类型分类的真实内容 |
| iOS 连不上内容源 | Capacitor 壳无内嵌 Node 服务：在电脑/NAS 上 `HOST=0.0.0.0 node server.js`，应用设置 → 播放 → **内容源网关** 填 `http://<局域网IP>:5173`（iOS 需 ATS 明文例外） |
| 某条线路报「片源网络错误」 | 第三方 m3u8 无 CORS 头时会自动走本机中转；若仍失败说明上游本身失效，会自动切换下一条线路 |
| `npm run desktop` 报找不到 electron | Electron 是可选增强；先 `npm i -D electron`，或直接用浏览器打开 `desktop.html` |
| `cap sync` 报 appId 非法 | 需先补 P-27 / P-28 的 Bundle ID / 包名；巨魔 IPA 构建已内置默认值，见 [14-巨魔IPA构建与网关部署.md](./14-巨魔IPA构建与网关部署.md) |
| 巨魔 IPA 装上后空白 / 转圈 | 网关未通：确认 fnos 上已跑代理且端口公网可达，或在 设置→播放→内容源网关 填可用地址 |
| 巨魔提示无法安装 IPA | 确认 IPA 是 `dist/ipa/AIStream-TrollStore.ipa`（ldid 伪签名版），且设备 iOS 在巨魔支持范围 |
