# AIStream 影视 · 分类提速、标签式 UI、我的页重构与开源播放器

> 2026-11-15 深夜第四轮改版。需求：① 切换分类导航会卡；② UI 做成标签形式；③「我的」标签里只放会员/积分信息、快捷入口多了一份；④ 内置播放器换开源方案，带弹幕与扩展；⑤ 播放器 UI 参考腾讯视频。

## 一、切换分类卡顿

**根因（三个叠加）**：站点 `api/up/catalog?kind=` 需要并行扫描多个采集站，本身慢；每次切分类都重新请求、无缓存；`store.refresh()` 没有请求序号，快速连点时旧请求回来会覆盖新分类的结果，看上去像「卡住 / 乱跳」。

**修复**：

| 措施 | 实现位置 | 效果 |
|------|----------|------|
| 列表内存缓存（5 分钟 TTL） | `datasource.js` 的 `listCache / peekList / putList` | 切回已看过的分类秒开 |
| 请求序号防竞态 | `store.js` 的 `refreshSeq` | 旧请求结果直接丢弃，不覆盖新分类 |
| 乐观切换 | `store.setChannel()` 先 `commit` 再发请求 | 高亮与已缓存内容立即出现，不等待网络 |
| 20 秒超时 | `datasource.api()` 用 `AbortController` | 站点无响应时给明确提示，不无限转圈 |
| 登录后强制刷新 | `init/login/register → refresh({force:true})` | 避免拿到上一个账号的缓存 |

`fetchByCategory` 仍只走实测的 `api/up/catalog?kind=`，失败回退 `/api/home` 真实内容并提示；不再用「栏目内筛选」冒充类型结果。

## 二、顶部标签式 UI

`CHANNELS` 保持上一轮的影视类型，样式改为**胶囊标签**：未选中半透明描边、hover 上浮、选中紫渐变 + 发光；IPTV 标签带红点直播标识。三端各自独立适配，不是同一套缩放：

- **桌面**：横排紧凑标签（gap 9px），键鼠 hover 反馈。
- **移动**：横滑胶囊 + scroll-snap，触控目标加大到 15px 内边距。
- **TV**：10-foot 大标签（20px 字号），选中放大 1.04 倍 + 焦点态。

「我的」页也统一用标签栏（圆角容器 + 选中紫渐变），TV 标签 18px 且遥控器可聚焦。

## 三、「我的」页标签化、快捷入口去重

之前主内容区有一份 6 项「快捷入口」卡片，侧栏又有一份完全相同的列表；且 IPTV 已在顶部分类里又出现一次。现在：

- `MINE_TABS` = `账户信息 / 我的追剧 / 历史记录 / 我的收藏 / 我的预约 / 搜索历史`，三端共用。
- **账户信息标签只负责会员卡、积分 / 签到 / 邀请码、版本关于**，不再混入影视卡片或片单。
- 追剧 / 历史 / 收藏 / 预约各自一个标签，点标签才加载对应实测接口；搜索历史只读本地记录。
- 主内容区**不再渲染快捷入口清单**（`mineContent` 不再调用 `quickEntries`），侧栏保留唯一一份全局快捷入口，点击直达对应标签。
- `QUICK_ENTRIES` 移除 `IPTV 直播`（顶部已有 IPTV 分类，避免重复入口）。

## 四、开源播放器内核（弹幕 + 扩展）

| 组件 | 版本 / 许可 | 位置 |
|------|-------------|------|
| ArtPlayer | 5.2.3 · MIT | `public/vendor/artplayer.js` |
| artplayer-plugin-danmuku | 5.3.0 · MIT | `public/vendor/artplayer-plugin-danmuku.js` |
| hls.js | 站点同款（已内置） | `public/vendor/hls.min.js` |

三个库全部**离线内置**，无 CDN；`player.js` 按需加载。m3u8 通过 ArtPlayer 的 `customType.m3u8` 复用内置 hls.js（含 Bearer 头注入与致命错误提示），mp4 等直链走原生 video。

**弹幕**：站点未提供弹幕接口，因此 `danmuku: []` 不编造任何弹幕内容；提供弹幕开关（`show/hide`）、输入框本地发送（`emit`）、设置里的「弹幕」开关。弹幕数据源已登记为待补充项 `play.danmukuSource`（P-07），后续给接口只需替换数据源数组。

**扩展口**：`window.AIStreamPlayer` 暴露 `use(plugin)`（注册任意 ArtPlayer 插件）、`art()`、`danmuku()`、`emitDanmuku(text, opt)`、`version`。这是「扩展」能力的落点。

## 五、腾讯视频式播放 UI

- 顶部：渐变标题栏 + 返回箭头 + 关闭。
- 画面：ArtPlayer 自带控制条（进度、倍速、音量、全屏、网页全屏、画中画），进度条改为腾讯视频橙。
- 悬浮功能条：弹幕开关「弹」+ 发送框 + 上一集 / 下一集 / 外部打开 / 复制链接，鼠标移入或聚焦时显现。
- 右侧：竖排「选集」面板（线路下拉 + 上一/下一线路 + 集数方块网格，选中橙色）+ 播放信息。
- 三端布局：桌面左右分栏 / 移动上下分栏且选集横滑 / TV 大焦点 430px 侧栏 + 遥控器方向键导航；BACK 先关播放器再退 App。

## 六、账户页布局（腾讯视频会员中心式）

按需求方截图重排，不再三列平铺：

- **上排**：左「我的账号」（头像 + 昵称 + 设置），右「关于」（AIStream 影视 / 版本 v1.0.0 / 内容源已连接 / 内置播放器 · 选集·线路·弹幕）。关于卡去掉了「经同源代理访问」这类技术说明。
