## 一、导航切换卡顿

**根因**：`setNav()` 每次都 `await refresh()`，即便当前分类数据已在内存里也要等一次接口；站点聚合接口本身慢，切换就表现为卡。

**修复**（`store.js`）：

```js
if (state.items.length && ds.peekList({ channel, page: 1, keyword: '' })) return;
```

首页 / 榜单 / 筛选三个入口共用当前分类的真实数据：已有内容且缓存有效时，切换是**纯前端重绘，零请求**。实测连切三次，请求计数 1 → 1 不变。

## 二、榜单页

原来「榜单」只是把首页区块标题换成「热播榜单」，内容与首页完全相同。现在有独立榜单视图（三端各自实现）：

- 桌面 / 移动：`rank-list` 列表，大序号（前三名暖金渐变）+ 小海报 + 片名 + 分类/年份/地区 + 播放按钮，最多 30 条。
- TV：横向货架 `榜单 · 内容源顺序` + 说明。
- 排序依据 = **内容源返回顺序**，界面明确标注「内容源顺序」，不编造播放量/热度。

## 三、筛选 / 排序（腾讯视频式）

新增 `src/components/filters.js` 四端共用：

| 筛选行 | 选项来源 | 是否真实 |
|--------|----------|----------|
| 类型 | `CHANNELS`（电影/电视剧/动漫/综艺/短剧/纪录片/点播/IPTV） | 站点实测 kind |
| 地区 | 当前列表条目 `area` 去重（最多 10 个） | 真实字段 |
| 年份 | 当前列表条目 `year` 去重，降序（最多 8 个） | 真实字段 |
| 排序 | 默认 / 年份新→旧 / 年份旧→新 / 按名称 | 前端对真实字段排序 |

切换类型会走 `/api/up/catalog?kind=`（有缓存秒开）；地区/年份/排序是**前端即时筛选**，不向站点发送未验证的参数。筛选页有「共 N 部」「重置筛选」和「选项来自真实条目」说明。

## 四、播放器修复 + 自动换源

- **自动换源**：`autoSwitch(reason)` 按线路切换，最多 3 次，失败线路记入 `failed` 不重复尝试；同集优先对齐，找不到同集回退该线路首集。
- **等待超时**：起播 12 秒仍未播 → 自动切下一条线路并提示。
- **致命错误**：HLS `NETWORK_ERROR` / 解码错误 / `art.on('error')` 都走自动换源，而不是只弹错误。
- **手动换源**：播放器功能条新增「换源」按钮，一键切下一条。
- **BUG 修复**：
  - 快速切集/换源可能并发生成多个 ArtPlayer 实例 → 加 `playToken` 序号，过期实例销毁。
  - 弹幕插件只在开关为开时加载，重建后状态错乱 → 改为**始终加载**，开关只做 `show/hide`。
  - 关闭播放器未清计时器 / 失败线路 → 现在统一清理。
  - 提示条 `.ais-player__tip` 显示「已自动切换到「线路 B」」。

## 五、现在能不能播放（实测）

| 验证 | 结果 |
|------|------|
| 内置 HLS 内核加载公开测试流 | `Hls=function`，`duration=635s`，**清单解析成功、无错误提示** |
| 播放状态 | 加 `--autoplay-policy=no-user-gesture-required` 后 `PAUSED=false`（已进入播放） |
| 无头环境画面 | `videoWidth=0`（headless 无 H.264 解码器），真机/桌面 App 有系统解码器，可正常出画面 |
| 你的站点 `/api/play` | 未登录返回 **401**，必须先在应用内登录才能取到真实播放地址 |
| 跨域片源 | 若线路未开放 CORS，HLS 会报网络错误 → 已自动换源 / 外部打开兜底 |

**结论**：播放器本身可播（HLS 加载 + 进入播放状态已实测）；你站点片源需要在应用里登录后点击播放；若某条线路报「网络错误」，会自动换下一条。

## 七、后续优化建议（按优先级）

**P0 播放体验**
1. 服务端流中转：加 `/api/proxy?u=`（支持 Range/302），解决第三方 m3u8/ts 的 CORS，预计能救回大部分「网络错误」线路。
2. 续播记忆：记录每部剧的集数与进度（本地 + 可用站点 `api/history` 写回）。
3. 线路测速：起播前并发探测各线路首片响应，优先选最快线路，减少 12 秒等待。

**P1 内容与筛选**
4. 服务端筛选参数：向站点确认是否支持地区/年份/排序参数；支持后改为服务端筛选，覆盖面从一页扩到全量。
5. 真实热度/评分排序：需要站点提供字段或接口，拿到后榜单可做「热度榜/新片榜」。
